# App Review 审核说明

拾序无需注册或登录，全部功能可以直接审核。

建议审核路径：

1. 首次启动后允许相机权限，对准纸张连续拍摄；也可以选择“从相册导入”。
2. 点击“完成”，检查自动透视校正和图像增强结果。
3. 在结果页调整四角、切换彩色/灰度/黑白效果或重新排序页面。
4. 点击“导出”，生成多页 PDF 或把 JPEG 保存到系统相册。
5. 从相机页右上角进入“隐私与关于”，可查看隐私政策和技术支持入口。

所有照片、处理结果与扫描历史均保存在设备本地。应用没有账号、广告、
分析 SDK、业务网络请求或远程上传功能。

在不提供相机输入的审核设备上，可通过系统照片选择器导入测试图片，完整验证
校正、编辑与导出链路。
